# «Код будущего» — преподавательская программа для macOS

Это отдельная macOS-сборка. Windows-версия и её данные не изменяются.

## Что сохранено

- изолированные постоянные профили аккаунтов;
- вкладки, переименование, подгруппы, флаг, масштаб и раскладка;
- панель бесплатных ИИ-помощников;
- очистка кэша и полный сброс отдельного аккаунта;
- экспорт и импорт `.kfb` для переноса между Mac;
- проверка новых версий и прямая загрузка DMG из официального GitHub Releases.

## Как собрать без Mac

1. Загрузите эту папку и Windows-исходники в репозиторий `Misha5757/PrepodKodBydyshie`.
2. Откройте **Actions → macOS · Преподаватель → Run workflow**.
3. Введите версию в формате `1.10.1` или `1.10.1-beta.1`.
4. После сборки готовые DMG для Apple Silicon и Intel появятся в **Releases**. Для быстрой загрузки ZIP больше не дублируется.

## Первый запуск

Без платного Apple Developer ID сборка имеет локальную ad-hoc подпись. После переноса в Applications macOS может один раз показать предупреждение. Откройте **System Settings → Privacy & Security** и нажмите **Open Anyway**. Отключать Gatekeeper не нужно.
